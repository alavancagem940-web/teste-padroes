# Projeto de Padrões — versão para celular

Esta versão mantém os arquivos de cálculo e a estrutura do projeto original.
As alterações desta versão são de compatibilidade visual/mobile e PWA.

## Teste no iPhone

1. Publique esta pasta em um endereço HTTPS.
2. Abra o endereço no Safari do iPhone.
3. Toque em Compartilhar.
4. Escolha "Adicionar à Tela de Início".
5. Abra pelo novo ícone.

Observação: abrir diretamente o index.html pelo app Arquivos não ativa a instalação PWA e não permite o service worker. O projeto precisa ser servido por HTTPS (ou localhost durante desenvolvimento).

## O que foi alterado

- manifest.json
- service-worker.js
- ícones
- meta tags para iPhone/Android
- ajustes responsivos na interface
- nada foi alterado deliberadamente nas métricas dos mercados.
